# GermanJobsPro — خط إنتاج الفيديو التوضيحي عالي الدقة (1080p Demo Video Pipeline) 🇩🇪

خط إنتاج وتسجيل مؤتمت ومستقل لإنشاء فيديو استعراضي عالي الدقة (**1920×1080 Full HD**) باللغة العربية (`/ar`) لمنصة **GermanJobsPro** مدته بين دقيقتين ونصف و3 دقائق (~170 ثانية)، جاهز لإضافة التعليق الصوتي، ومحول تلقائياً إلى صيغة **H.264 MP4** المتوافقة مع كافة برامج المونتاج وشبكات التواصل، ومرفق بسكريبت تعليق صوتي عربي موثق بالثواني.

---

## 📋 المتطلبات المسبقة (Prerequisites on Fedora)

1. **FFmpeg:** مثبت مسبقاً على النظام (`ffmpeg version 7.1.5` متوفر ويدعم `libx264`).
   *(إذا كنت تعمل على نظام آخر: `sudo dnf install -y ffmpeg`)*
2. **Node.js:** الإصدار 18+ (مثبت حالياً: `v22.22.2`).
3. **Playwright:** لتثبيت Playwright بدون تعديل ملف `package.json` الرئيسي للمشروع، نفذ الأمر التالي لمرة واحدة:
   ```bash
   npm install --no-save playwright
   npx playwright install chromium
   ```

## 🚀 خطوتان لتسجيل وإنتاج الفيديو (Quick Start)

### الخطوة 1: تسجيل الدخول لمرة واحدة بحساب العرض (One-Time Auth Capture)
افتح المتصفح المرئي لتسجيل الدخول بحساب العرض **Demo Pro**:
```bash
node scripts/demo-video/record-demo-ar.mjs --login
```
1. سيفتح متصفح Chromium بملء الشاشة على صفحة الدخول: `https://www.germanjobspro.com/ar/auth/login`.
2. سجل دخولك بحسابك التجريبي (عبر Google أو البريد الإلكتروني).
3. بمجرد ظهور لوحة التحكم (`/ar/dashboard`)، ارجع إلى الطرفية واضغط **[ENTER]**.
4. سيتم حفظ ملف الجلسة محلياً في `scripts/demo-video/.auth-state.json` (محمي ومستبعد في `.gitignore`).

---

### الخطوة 2: تشغيل التسجيل المؤتمت وتحويل MP4 تلقائياً
شغّل خط الإنتاج لتنفيذ الرقصة البصرية الكاملة وتسجيل المشاهد السبعة:
```bash
node scripts/demo-video/record-demo-ar.mjs
```
*(أو أضف `--headed` إذا كنت ترغب في مشاهدة المتصفح وهو ينفذ المشاهد مباشرة: `node scripts/demo-video/record-demo-ar.mjs --headed`)*

## 🎬 المشاهد السبعة للتسجيل (7-Scene Choreography ~170s)

| المشهد | المسار (Route) | المدة | الوصف التقني والحركي |
|:---:|:---|:---:|:---|
| **1** | `/ar` | ~20 ثانية | الصفحة الرئيسية، حركة الماوس، استعراض مركز الأدوات الستة ومقارنة معيار DIN 5008. |
| **2** | `/ar/jobs` | ~25 ثانية | منصة الوظائف الألمانية الحية، فلترة الوظائف (تكنولوجيا/لغات)، واستعراض بطاقات الوظائف ودعم الفيزا. |
| **3** | `/ar/dashboard` | ~20 ثانية | لوحة التحكم المتكاملة Pro باللغة العربية (RTL) واستعراض أدوات مساحة العمل. |
| **4** | `/ar/dashboard/cv` | ~30 ثانية | منشئ السيرة الذاتية DIN 5008، التنقل في الأقسام، معاينة Lebenslauf، والتمرير فوق زر 1-Click PDF. |
| **5** | `/ar/dashboard/ats-analyzer` | ~25 ثانية | فاحص الـ ATS ومعايير التوافق الألمانية وقسم خطة العمل والتطوير. |
| **6** | `/ar/dashboard/cover-letters` | ~25 ثانية | مولد خطاب التغطية Anschreiben المعتمد على الذكاء الاصطناعي مع شارة `✓ محفوظ` وتنسيق الرسالة الرسمية. |
| **7** | `/ar/dashboard/dossier` → `/ar/pricing` | ~25 ثانية | ستوديو تجميع ملف الترشيح الكامل (Bewerbungsmappe) ثم الانتقال إلى صفحة الأسعار وعرض Pro كخاتمة CTA. |

## 📁 المخرجات والملفات الناتجة (Output Artifacts)

تُحفظ كافة المخرجات داخل مجلد `scripts/demo-video/output/`:
- **`scripts/demo-video/output/germanjobspro-demo-ar-1080p.mp4`**:  
  فيديو عالي الجودة بدقة 1080p (30 FPS) بصيغة H.264 عالمية، صامت وجاهز للمونتاج وإضافة التعليق الصوتي في CapCut أو Premiere Pro أو DaVinci Resolve أو رفعه مباشرة على YouTube / LinkedIn.
- **`scripts/demo-video/output/voiceover-script-ar.md`**:  
  سكريبت التعليق الصوتي باللغة العربية موثق بالتوقيت الفعلي الدقيق لكل مشهد، ومرفق بدليل نطق المصطلحات الألمانية الرسمية (DIN 5008, Lebenslauf, Anschreiben, Bewerbungsmappe).
- **`scripts/demo-video/output/raw/`**:  
  تسجيلات الفيديو الخام بصيغة WebM الصادرة من محرك Playwright قبل معالجة FFmpeg.

## 🔒 الأمان والخصوصية (Security & Privacy)

- ملف بيانات الجلسة `.auth-state.json` ومجلد المخرجات `output/` مستبعدان بالكامل من تتبع Git في `.gitignore`.
- لا يتم استدعاء أو زيارة أي مسارات إدارية خاصة (`/ar/admin`) ولا تظهر أي بيانات حساسة أو بريد إلكتروني خاص للمستخدمين أثناء التسجيل.
- جميع عمليات التفاعل مع واجهة المستخدم مغلفة بآليات أمان استباقية (`try/catch` مع مهلات ذكية) لضمان عدم توقف التسجيل عند أي تحديث في الواجهة.
